# Shared fixtures

These fixtures are intentionally fictional and contain no real student data.

- `csv/terics_sample.csv`: canonical long-form CSV adapter fixture.
- `html/qingguo_list_sample.xls`: synthetic Qingguo-style list table using a structure documented by the MIT-licensed `LingNc/stnet_syllabus` project.
- `html/wakeup_usc_sample.html`: copied from `Ricraft/wakeup-schedule` (MIT); see `THIRD_PARTY_NOTICES.md`.
- `xlsx/wakeup_schedule_template.xlsx`: copied from `Ricraft/wakeup-schedule` (MIT); see `THIRD_PARTY_NOTICES.md`.
- `normalized/example.json`: schema example and parity reference.
