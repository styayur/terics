## Stable 门禁结论

以下 Stable 门禁在本环境无法全部满足：

- 真实 WHUT 登录与完整学期提取
- 真实 Google OAuth 授权
- 独立测试日历完整学期写入
- 重复同步 Update / Skip 验收
- 整门课程 Calendar 删除
- Google Calendar 网页端 UI 核验

因此本线只能发布 **`v0.6.0-rc.1` Release Candidate**，不得标记为 Stable，不得把 mock、fixture 或 API HTTP 200 替代为真实账号验收。
