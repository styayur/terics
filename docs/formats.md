# 支持的输入格式

v0.5.0-rc.2 的文件导入仍按内容识别格式，不依赖扩展名。

## 1. CSV / TSV 长表

推荐 UTF-8（可带 BOM），也识别 GB18030。逗号、分号、制表符由解析器自动判断。

必需列：

- `课程` / `课程名称` / `course`
- `周次` / `weeks`
- 以及 `星期`/`weekday` 或包含星期的时间列

推荐列：

- `教师` / `teacher`
- `地点` / `教室` / `location`
- `节次` / `periods`
- `备注` / `note`

示例：

```csv
课程,教师,地点,星期,节次,周次,备注
高等数学A,张伟,教1-101,周一,1-2,1-16,
大学英语,李华,外语楼204,周二,3-4,1-16单,
数据结构,王芳,计算机楼305,周三,3-4,"1-8,10-16",含实验周
```

也支持将星期、节次、周次、地点写在同一个“上课时间地点”字段中：

```text
1-16周 一[1-2节] 教1-101；1-16周 三[3-4节] 教1-101
```

多个时间地点段使用中文或英文分号分隔。

## 2. HTML 表格

### 2.1 青果列表式

表头包含课程、教师以及“上课时间地点”等列。时间地点字段可包含多段：
`1-16周(单) 二[5-6节] 计算机楼305`。

`html/qingguo_list_sample.xls` 是脱敏、虚构的结构样本，文件扩展名为 `.xls`，内容实际为 HTML。程序会按内容识别为 HTML。

### 2.2 节次 × 星期网格

表头列包含周一至周日，首列包含节次。课程单元格支持：

```text
课程名 {第1-16周 张老师 A101
```

或多行：

```text
高等数学
{第1-16周
张老师
A101
```

以及管道字段：

```text
高等数学|老师|张伟|周次(节次)|1-16(周)[01-02节]|教室|A101
```

同一单元格内用 `---` 分隔可表示多门课程。

公共 MIT 样本：`fixtures/html/wakeup_usc_sample.html`，来源 `Ricraft/wakeup-schedule`。

## 3. XLSX

仅支持 Office Open XML `.xlsx`（ZIP 签名 `PK`）。

支持两种工作表布局：

1. **周网格**：首行是节次与星期表头；前六到八列通常为周一至周日。
2. **课程长表**：与 CSV 相同的课程/教师/地点/星期/节次/周次列。

公共 MIT 模板：`fixtures/xlsx/wakeup_schedule_template.xlsx`。程序会忽略“使用说明”等非课表工作表。

不支持旧版 OLE 二进制 `.xls`。如果学校导出扩展名是 `.xls`，请先用文本编辑器确认其内容是否为 HTML；若是 HTML，可直接拖入。

## 4. 周次写法

- `1-16`
- `第1-16周`
- `1-16单` / `1-16周(单)`
- `2-16双` / `2-16周(双)`
- `1-8,10-16`
- `1,3,5,7`
- `4,8,12,16`

传统 HTML/CSV/XLSX 文件导入最高支持第 30 周。SIS schema 2.0 的 WHUT 位图解析按完整长度处理，不以 30 周截断。

## 5. 节次写法

- `1-2`
- `第3-4节`
- `[05-06节]`
- `五[3-4]`（在包含星期的时间字段中）

节次由用户在界面确认。不同学校作息差异很大，默认时间表仅作为起点，不是官方标准。

## 6. 已知限制

- 不登录教务系统，不抓取网页。
- 不支持扫描图片、PDF、加密 XLSX、宏或旧版 OLE `.xls`。
- `.terics.json` schema 2.0 支持多套有效期节次表；传统 CSV/HTML/XLSX 文件导入仍使用用户确认的一套节次。
- 不自动识别学期第一周周一；必须由用户确认。
- 不合并跨节次但中间有休息的课程为单一连续块。
- 仅经过测试样本验证的字段组合可稳定导入；本校变体可能需要贡献 Adapter。

提交新格式前请使用虚构/脱敏数据，并阅读 `CONTRIBUTING.md`。


## 7. `.terics.json` schema 2.0

浏览器扩展、Web 和 Python 桌面版之间使用统一交换格式。顶层字段：

- `schemaVersion: "2.0"`
- `source`
- `term`
- `courses`
- `overrides`
- `metadata`
- `validation`
- optional `warnings`

关键特性：

- 稳定 `course.id` / `meeting.id`；
- 周次显式数组；
- `periodSchedules` 支持生效日期范围；
- `overrides` 支持停课、调课、补课、教室/教师/节次变更；
- `validation.completeness` 明确缺失字段；
- 禁止 credential-like 字段。

Schema: `schema/timetable-v2.schema.json`。

Web/Python 可直接导入该文件。扩展可通过 URL fragment 打开 Web，也可下载 `.terics.json`。
